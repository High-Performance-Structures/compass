## 5.5 Entity-relationship diagrams by domain

> Generated by `scripts/manual/generate-appendices.ts` from the source tree. Do not edit by hand; rerun `bun scripts/manual/build.mjs`.

One diagram per domain. Each box shows a table's primary key and foreign-key columns; the full column list is in Appendix A. Edges to `users`, `organizations` and `projects` are drawn only in their own domain's diagram, because almost every table carries `created_by`, `organization_id` or `project_id`. Rows marked `key` are primary-key columns and `ref` foreign-key columns; foreign keys to those three shared tables are left out of the boxes too. A box with only `id` is a table from another domain that this domain points to.
