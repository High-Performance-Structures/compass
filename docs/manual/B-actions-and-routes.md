## B.2 API routes (130)

Route handlers under `src/app/api/`. **Auth** is inferred from the code: `signed request (HMAC)` routes verify `X-Compass-Timestamp` / `X-Compass-Signature` with the bridge secret (scheduled jobs and on-premises agents use these); `provider webhook signature` routes verify the provider's own signature header; `session` routes require a signed-in user.
